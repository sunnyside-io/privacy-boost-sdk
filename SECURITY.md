# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to
**contact@sunnyside.io**, not in public issues or pull requests.

Include the affected platform (TypeScript, React, React Native, iOS, Android or
CLI), the SDK version, and steps to reproduce if you have them.

## Supported versions

Security fixes ship in the next release of each affected platform. Use the
latest version of each platform listed in the [README](README.md#packages), and
check the **Security** sections of the [changelog](CHANGELOG.md).
